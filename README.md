# FUTURE_ML_03 – Customer Support Chatbot

## 📌 Task Overview
This project is part of the **Future Interns – Machine Learning Internship (Task 3)**.  
The goal is to build an AI-powered chatbot capable of handling basic customer support queries using Natural Language Processing (NLP).

---

## 🚀 Features
- Intent-based customer query handling
- NLP text preprocessing
- TF-IDF vectorization
- Machine Learning classification model
- Fallback handling for unknown queries
- Streamlit-ready web interface

---

## 🛠️ Technologies Used
- Python
- Pandas, NumPy
- NLTK
- Scikit-learn
- Streamlit
- Google Colab
- 
---

## ⚙️ How It Works
1. Customer queries are preprocessed using NLP techniques.
2. TF-IDF converts text into numerical features.
3. Logistic Regression predicts the intent.
4. The chatbot responds based on predefined intent-response mapping.
5. Unknown queries trigger a fallback response.

---

## 📸 Output
The chatbot successfully responds to customer queries such as:
- Password reset
- Refund policy
- Contact support
- Order tracking

---

## 🎯 Learning Outcomes
- NLP preprocessing techniques
- Text classification using Machine Learning
- Chatbot logic and conversational flow
- Basic deployment preparation with Streamlit
